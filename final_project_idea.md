01. FORKED — What If Simulator
Top pick









devpost.com


Concept: What if you could explore different versions of the same decision?

Users describe a situation, and AI creates multiple possible scenarios. They make decisions, explore branching outcomes and compare different timelines.

Example:
- What if I start a business with Rs. 100,000?
- What if I move to another city?
- What if I choose a different career?
- What if I launch a new product?
Core features
- AI-generated interactive scenarios.
- Multiple decision paths and branching timelines.
- Resource management: money, time, risk and progress.
- Compare two or more possible outcomes.
- Save, edit and revisit simulations.
- AI explains the consequences of decisions.
AI's role: Generates scenarios, consequences, events and narrative explanations. A backend simulation engine handles numerical rules and state transitions.

Unique factor: It is an interactive decision laboratory, not a chatbot. Outcomes are simulations, not guaranteed predictions.

5. What makes this project technically impressive?
The most important part is that we won't let AI do everything.

We'll divide the application into three engines:
1. AI Engine: Generates situations, choices, events and explanations.
2. Simulation Engine: Processes decisions, calculates resource changes and manages branching logic.
3. Data Engine: Stores users, simulations, decisions, timelines and historical results.
This separation will make the application much more interesting from a software engineering perspective.
