`java → package → SplashActivity.java` create karo.

java

```java

package com.example.studentformapp;

import android.app.Activity;
import android.content.Intent;
import android.os.Bundle;
import android.os.Handler;
import android.os.Looper;

public class SplashActivity extends Activity {

    private final Handler handler =
            new Handler(Looper.getMainLooper());

    private final Runnable splashRunnable = () -> {
        startActivity(new Intent(
                SplashActivity.this,
                MainActivity.class
        ));
        finish();
    };

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);

        setContentView(R.layout.activity_splash);

        handler.postDelayed(splashRunnable, 3000);
    }

    @Override
    protected void onDestroy() {
        handler.removeCallbacks(splashRunnable);
        super.onDestroy();
    }
}
```

Samajhne wali baat:

- `Handler`: delay lagata hai.
- `3000`: 3 seconds.
- `Intent`: Splash se Main Activity par move karta hai.
- `finish()`: Splash Activity close karta hai.

### File 4: MainActivity.java

`MainActivity.java` mein ye complete code paste karo.

java

```java

package com.example.studentformapp;

import android.app.Activity;
import android.os.Bundle;
import android.content.Intent;
import android.content.SharedPreferences;
import android.widget.Button;
import android.widget.EditText;
import android.widget.CheckBox;
import android.widget.Toast;

public class MainActivity extends Activity {

    EditText etName, etEmail, etAddress, etPassword;
    CheckBox checkBox;
    Button btnWelcome, btnSubmit;

    SharedPreferences preferences;

    @Override
    protected void onCreate(Bundle savedInstanceState) {
        super.onCreate(savedInstanceState);
        setContentView(R.layout.activity_main);

        // Connect XML views
        etName = findViewById(R.id.etName);
        etEmail = findViewById(R.id.etEmail);
        etAddress = findViewById(R.id.etAddress);
        etPassword = findViewById(R.id.etPassword);
        checkBox = findViewById(R.id.checkBox);

        btnWelcome = findViewById(R.id.btnWelcome);
        btnSubmit = findViewById(R.id.btnSubmit);

        // Shared Preferences
        preferences = getSharedPreferences(
                "UserData", MODE_PRIVATE);

        // Load previously saved data
        etName.setText(preferences.getString("name", ""));
        etEmail.setText(preferences.getString("email", ""));
        etAddress.setText(preferences.getString("address", ""));
        etPassword.setText(preferences.getString("password", ""));
        checkBox.setChecked(
                preferences.getBoolean("agree", false));

        // Welcome Button
        btnWelcome.setOnClickListener(v -> {
            Toast.makeText(
                    MainActivity.this,
                    "Welcome to Student App!",
                    Toast.LENGTH_SHORT
            ).show();
        });

        // Submit Button
        btnSubmit.setOnClickListener(v -> {

            String name = etName.getText().toString().trim();
            String email = etEmail.getText().toString().trim();
            String address = etAddress.getText().toString().trim();
            String password = etPassword.getText().toString();
            boolean agree = checkBox.isChecked();

            if (name.isEmpty() || email.isEmpty()
                    || address.isEmpty() || password.isEmpty()) {

                Toast.makeText(this,
                        "Please fill all fields",
                        Toast.LENGTH_SHORT).show();
                return;
            }

            if (!android.util.Patterns.EMAIL_ADDRESS
                    .matcher(email).matches()) {
                etEmail.setError("Enter valid email");
                return;
            }

            if (!agree) {
                Toast.makeText(this,
                        "Please accept terms and conditions",
                        Toast.LENGTH_SHORT).show();
                return;
            }

            // Save data in SharedPreferences
            SharedPreferences.Editor editor =
                    preferences.edit();

            editor.putString("name", name);
            editor.putString("email", email);
            editor.putString("address", address);
            editor.putString("password", password);
            editor.putBoolean("agree", agree);

            editor.apply();

            Toast.makeText(this,
                    "Data Saved Successfully",
                    Toast.LENGTH_SHORT).show();

            // Move to Detail Activity
            Intent intent = new Intent(
                    MainActivity.this,
                    DetailActivity.class);

            startActivity(intent);
        });
    }
}
```

Is code mein important concepts:

- `findViewById()`: XML controls ko Java se connect karta hai.
- `setOnClickListener()`: Button click handle karta hai.
- `Toast`: Short message show karta hai.
- `SharedPreferences`: Data save karta hai.
- `editor.apply()`: Data asynchronously save karta hai.
- `Intent`: Main se Detail Activity open karta hai.

```java
import android.app.Activity;

public class DetailActivity extends Activity {
```

# 8. Activity Lifecycle (Requirement E)

Exam mein ye concept zaroor likhna.

Android Activity Lifecycle ke important methods:

| Method | Kaam |
| --- | --- |
| `onCreate()` | Activity create hoti hai, layout initialize hota hai |
| `onStart()` | Activity user ko visible hoti hai |
| `onResume()` | Activity user ke saath interact karti hai |
| `onPause()` | Activity partially hidden hoti hai |
| `onStop()` | Activity completely hidden hoti hai |
| `onDestroy()` | Activity destroy hoti hai |

Humare project mein lifecycle ka usage:

1. `SplashActivity` ke `onCreate()` mein splash screen show hoti hai.
2. 3 seconds baad Intent se MainActivity open hoti hai.
3. `MainActivity` ke `onCreate()` mein form initialize hota hai.
4. SharedPreferences se previous data load hota hai.
5. Submit par data save hota hai.
6. `DetailActivity` ke `onCreate()` mein saved data display hota hai.
7. SplashActivity ke `onDestroy()` mein pending Handler callback remove hota hai.

# 9. SharedPreferences kya hai?

SharedPreferences Android ka local storage mechanism hai jo small data key-value pairs mein save karta hai.

Example:

java

```java
SharedPreferences sp =
    getSharedPreferences("UserData", MODE_PRIVATE);

SharedPreferences.Editor editor = sp.edit();

editor.putString("name", "Ali");
editor.putString("email", "ali@gmail.com");

editor.apply();
```

Data retrieve karna:

java

```java
String name = sp.getString("name", "");
String email = sp.getString("email", "");
```

Advantages:

- Data app restart hone ke baad bhi available rehta hai.
- Small data ke liye useful hai.
- Simple aur easy to use hai.

Security noteYe assignment demo password ko plain text mein save aur display karta hai. Real applications mein password ko SharedPreferences mein plain text save ya screen par display nahi karna chahiye. Secure authentication use karni chahiye.

```xml
                android:text="Submit"/>

        </LinearLayout>

    </LinearLayout>
</ScrollView>
```

Result: Portrait mein fields vertical hongi aur Landscape mein 2 columns mein show hongi.

Detail Activity ke liye bhi isi tarah `layout-land/activity_detail.xml` bana sakte ho. Usmein existing detail screen ko horizontal arrangement mein adjust karo aur saare original TextView IDs same rakho.

## Exam mein G–K ka short explanation

- G: ConstraintLayout provides flexible positioning of UI components and supports responsive screen design.
- H: Landscape qualifier provides a separate layout for horizontal screen orientation using the `layout-land` folder.
- I: INTERNET permission allows the application to access the internet.
- J: Custom launcher icon replaces the default Android application icon.
- K: Consistent colors, responsive layouts, input validation and efficient storage improve app usability and performance.

Ek important baat: Purane Java code ko change nahi karna. Sirf XML layouts, Manifest aur launcher icon update karne hain. Is tarah Q1 ke A–F aur naye G–K ek hi project mein complete ho jayenge.
